# CtrlC 手机端与 CtrlV 电脑端使用指南

按 0.4.10 的按钮与行为说明。两端安装包在 [GitHub Releases](https://github.com/Flechazo-YQ/suishouchuan/releases/latest)。

## 1. 第一次安装和配对

1. 电脑安装 `CtrlV-Setup-0.4.10.exe`，打开CtrlV。关主窗口后仍在系统托盘接收；选择退出则停止接收。
2. 手机浏览器下载 `CtrlC-0.4.10-android-arm64.apk`，按 Android 提示允许当前来源安装。
3. 两端连接同一可互通的局域网。电脑用网线、手机用 Wi-Fi 也可以，前提是路由器允许两者通信。
4. 电脑点「配对手机」，手机点顶部设备栏 →「扫描配对二维码」。
5. 扫描后核对电脑名称并确认。顶部显示电脑名称或地址，以后默认发给这台电脑。

二维码短期、一次有效，过期后重新生成。多部手机可以分别配对同一电脑；最后成功复制的素材成为当前剪贴板内容。

功能需要的权限：相机用于拍摄/扫码，麦克风用于相机录像，悬浮窗、屏幕采集和相关通知用于截屏/录屏。分享已有图片不需要相机权限。

## 2. 例子：拍一张照片，喂给 AI

假设你想让 AI 分析一个实物的外观。

**原来的流程**：系统相机拍照 → 微信 → 文件传输助手 → 电脑微信 → 复制 → 切回 AI → 粘贴。

**现在的流程**：

1. 手机打开 CtrlC，选择「拍摄」，对准物品，短按快门。
2. 大图预览中，不满意点左上「×」重拍；满意点右上「✓」，确认上传到显示的电脑。
3. 等电脑提示「已复制」，在支持图片的 AI 输入框按 Ctrl+V。
4. 输入「请描述这件物品的外观，帮我写三条商品介绍」，检查附件后自己发送对话。

CtrlC 与 CtrlV 负责手机到电脑的局域网传输。你在 AI 软件中提交之后，才进入该软件自己的处理流程。

## 3. 例子：连续拍 3 张，让 AI 看不同角度

**原来的流程**：拍正面/侧面/背面 → 相册找三张 → 发微信 → 电脑保存 → 给 AI 添加附件。

**现在的流程**：

1. 点「连拍」，或向左滑动取景画面。
2. 每换一个角度点一次快门，照片出现在下方缩略图。
3. 点缩略图或「查看 3 张」进入大图预览，逐张检查；缩略图「×」可移除。
4. 右上「确认并发送」一次完成，不需要下方确认或第二次图集发送弹窗。
5. 在支持多文件粘贴的电脑输入框按一次 Ctrl+V，三张独立图片一起出现。

每组最多 10 张。Codex 桌面端已验证十张一次粘贴；其他客户端的附件限制可能不同。

## 4. 例子：连续截 3 个小程序页面

**原来的流程**：第一页系统截图 → 截图面板 → 换页再截 → 从相册整理 → 传到电脑。

**现在的流程**：

1. 点快门右侧「截屏 / 录屏」，允许悬浮窗与本次屏幕采集。
2. 打开小程序，停在第一页，点悬浮「截一张」。成功会闪屏并出现缩略图。
3. 切到第二页，等画面稳定后再截；第三页重复。
4. 点「查看图片 (3)」返回 CtrlC 预览，检查并移除不需要的图。
5. 点右上「确认并发送」，电脑 Ctrl+V；例如提问「请检查这三个页面的布局一致性」。

此入口不调用小米系统截图按钮，不走系统截图面板。手机自带截图快捷键不会自动加入这组；已有系统截图可从相册选择或系统分享发送。

按住「按住拖动」移动浮窗，右上「×」结束采集，有图时先返回预览。页面动画切换时可能截到过渡画面；受系统保护的页面可能模糊或为空，不绕过系统保护。

## 5. 例子：已有的 9 张或 10 张图一次发给 AI

1. 点快门左侧相册图标，选 1–10 张；部分系统选择器要长按第一张进入多选。
2. 确认选择后自动传到默认电脑，不用在 App 再点上传。
3. 整组已复制后，在兼容输入框按一次 Ctrl+V。

也可从系统相册多选 → 分享 → CtrlC。系统单图分享先进入单张预览确认，系统多图分享按图集自动发送；来源相册原图不会被删除。

图集是独立图片文件，不拼长图、不压缩打包。一些输入框只接受单图或不接受文件粘贴，可以在电脑接收记录另存为，再用目标软件「添加附件」。

## 6. 例子：给 Word / WPS 文档配图

**原来的流程**：拍照 → 发微信 → 电脑保存到文件夹 → 文档插入图片 → 找到文件。

**现在的单图流程**：CtrlC「拍摄」模式拍一张 → 确认上传 → 文档定位光标 → Ctrl+V。

支持系统图片剪贴板的位置可以直接插图。如果该位置不接受图片，或发送的是相册/连拍图集（文件剪贴板），先在电脑CtrlV另存为，再用文档「插入 → 图片」。文档里的最终图片不再依赖CtrlV缓存。Word/WPS 的多文件处理未作为全版本兼容承诺。

## 7. 连拍到一半，临时选图或录屏

例如已经拍了两张商品照，想补一张相册参考图：直接点相册 → 选参考图 → 参考图单独自动发送 → 回到原两张连拍。两组不会混在一起。

改成截屏/录屏也一样：原连拍保留，新截图/视频独立预览。点「待发 N 张 · 查看」或「待发视频 · 查看」可来回切换。取消相册选择或屏幕授权不改原组。

这些仅是当前运行会话的临时待发素材。不要把退出/重启 App 当成保存草稿；进程重启会清理遗留文件。

## 8. 短视频与屏幕录像

相机录像：在「拍摄」模式长按快门，松手结束，最长30秒。首次允许麦克风后，再长按开始。预览后点右上勾确认上传。

屏幕录像：右侧入口 → 浮窗「录屏」→「开始录屏」。录制中显示计时和红色停止按钮，可提前结束，满30秒自动停止。回App预览后再确认上传。

屏幕录像为无声MP4；计时浮窗会录进去，可以拖到角落。切换屏幕方向会结束本次录屏。电脑剪贴板是视频文件，需要目标软件支持；否则另存为再添加。

## 9. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到电脑或超时 | 检查电脑程序是否运行、是否暂停接收，两端是否互通；访客Wi-Fi、AP隔离、VPN与防火墙可能阻断连接。重新扫码直连 |
| 二维码失效 | 电脑刷新二维码，重新扫描 |
| 拍摄画面黑色 | 允许相机权限；已拒绝时用页面中的系统权限入口恢复 |
| 已接收但不能粘贴 | 要等「已复制」；Windows锁屏或剪贴板占用时先解锁，再手动重试 |
| 上传失败 | 确认电脑在线、目标设备正确，再手动重试；失败不会显示成功 |
| Ctrl+V没图或只有文件 | 检查输入框支持的类型：单拍是图片，图集/视频是文件；必要时另存为后插入 |
| 截图模糊 | 等动画结束再截；系统保护页面不能保证采集 |
| 手机相册没有新照片 | 预期行为：只使用私有临时文件，成功传输后清理 |
| 电脑旧图片不见了 | 混合缓存最多100MB，旧素材自动回收；重要内容请另存为 |
| 两部手机先后发送 | 后成功复制的素材替换当前剪贴板；未被回收的接收记录仍可重新复制 |
| Android更新失败 | 使用同签名的新版本；自行构建的签名不同，不能覆盖发布包。不要为降级随意卸载清空配对 |
| Windows提示未知发布者 | 当前个人测试安装包未做Windows代码签名；从本仓库Release下载并核对SHA-256，按自己的设备策略决定是否运行 |
